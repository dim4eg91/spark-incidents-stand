# orders_intro.csv

Учебный набор первого урока.

Grain: одна строка соответствует одному заказу.

Ключ: `order_id`.

| Поле | Тип в Spark | Смысл |
|---|---|---|
| `order_id` | string | идентификатор заказа |
| `created_at` | date | дата создания |
| `status` | string | `new`, `paid`, `cancelled` или `refunded` |
| `region` | string | учебный регион |
| `customer_id` | string | идентификатор клиента |
| `amount` | double | сумма заказа |

Набор синтетический, персональных данных не содержит.

Контрольные инварианты:

- 30 строк;
- 30 уникальных `order_id`;
- нет NULL в ключе;
- фильтр урока возвращает 7 строк;
- мини-лаборатория возвращает 9 строк.

## orders_contract_issues.csv

Отдельный набор для диагностики входного контракта:

- 8 строк;
- 6 уникальных непустых `order_id`;
- 1 строка с пустым ключом;
- ключ `i002` встречается дважды.

Ошибки добавлены намеренно. Notebook урока 2.2 должен их обнаружить и сохранить
исходные строки без исправления.

## typed_values.csv

Вход для урока 2.7. Десять синтетических записей, одна строка соответствует
записи источника, ключ `row_id`. Поля `date_text` и `amount_text` при чтении
остаются строками. В них специально добавлены пустота, неверный формат,
отрицательная сумма и переполнение `DECIMAL(10,2)`. Ошибочные строки не удаляются
до типизации и назначения причины.
