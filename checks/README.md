# Публичные проверки стенда

В публичном репозитории остаются только проверки работоспособности окружения. Команда `scripts/health.ps1` проверяет HTTP-интерфейсы, запуск Spark-приложения и наличие двух executors.

Проверки учебных ответов, эталонные реализации и скрытые наборы данных сюда не входят. Они разрабатываются в авторском контуре Stepik и публикуются только через выбранный механизм автоматической проверки.
